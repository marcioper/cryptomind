# CryptoMind

CryptoMind is an intelligent, AI-powered crypto portfolio manager.  
It connects to multiple exchanges, provides real-time portfolio insights, and leverages AI for trading recommendations.

## Main Technologies
- Java, Spring Boot, Spring Cloud, WebFlux, GraphQL, gRPC
- Python (AI agent)
- Kafka, Redis, PostgreSQL
- Docker, Kubernetes, Terraform
